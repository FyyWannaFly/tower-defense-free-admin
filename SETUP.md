# Tower Defense Free Admin - Roblox Studio

Versi sederhana dan siap pakai untuk game Tower Defense di Roblox Studio.

## Fitur
- tower placement via click
- enemy jalan otomatis
- gold + lives + round
- tower otomatis menembak
- UI basic

## Cara pakai
1. Buka Roblox Studio
2. Buat project baru
3. Buka ServerScriptService
4. Masukkan script utama dari README atau dari file yang terlampir di repo
5. Buat LocalScript di StarterGui untuk UI
6. Klik Play

## Catatan
Ini adalah versi cepat dan ringan supaya bisa langsung dimainkan tanpa kompleksitas besar.
